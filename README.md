# 林的训 PWA（新版训练工作台）

## 本版更新
- 训练主页先展示训练计划：默认训练 A、训练 B；可自定义创建和管理训练计划。点击计划后进入训练工作台。
- 训练中显示计时、完成组数、每个动作卡片和醒目的“完成一组”。
- 底部四栏：训练、记录、统计、动作；主页不再先展示 A/B 两个大入口。
- 训练模板、动作库、每组重量/次数、引体向上辅助重量、自动带入上次表现、PR、训练日历、月训练时长、身体数据。
- 休息倒计时支持提示音/振动（后台和锁屏提醒受浏览器限制）。
- JSON/CSV 导出、JSON 导入；支持浏览器本地保存。
- 首次打开新版时会尝试把旧版 `lin-de-xun-v1` 的训练历史迁移到新版数据结构；旧 key 不会删除。

## 发布更新
1. 解压本压缩包。
2. 打开 GitHub 仓库 `linwen2588/lin-de-xun`。
3. 点击 Add file → Upload files，把压缩包内所有文件直接上传到仓库根目录，覆盖同名文件。
4. Commit changes。GitHub Pages 会自动重新部署，稍等 1–3 分钟后刷新网页。
5. 已安装的 PWA 关闭后重新打开/刷新，等待 Service Worker 更新。

## 数据说明
数据保存在当前设备、当前浏览器的 localStorage。手机与电脑各自保存，不会自动同步。定期导出 JSON 备份。旧版训练记录会尝试自动迁移；身体数据保留在旧版存储中，不会被删除。
